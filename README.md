## 🌟 Overview

This repository contains the source code for my personal portfolio website, designed to showcase my engineering background, flagship projects, technical skills, and software development philosophy.

### ✨ Highlights & Features

- **Cyber-Modern Aesthetic**: Responsive dark-mode interface with ambient glowing gradients, glassmorphism, and an interactive particle network canvas.
- **Flagship Production Projects**:
  - **[DigiCow AI](https://digicow-ai-farmer-intelligence-ui.onrender.com/)**: Farmer intelligence decision support engine powered by Neo4j knowledge graphs, GraphRAG, and Featherless AI for zero-hallucination bilingual advisories.
  - **[LedgerMate](https://ledger-mate-ecru.vercel.app/)**: Small business bookkeeping platform with Paystack / M-Pesa STK push & C2B webhook auto-reconciliation, inventory weighted-average costing, and automated P&L / Balance Sheet generation.
  - **[js-lings](https://github.com/Moraa021/js-lings)**: Local gamified JavaScript test runner inspired by Rustlings.
  - **Go Systems Engineering**: High-throughput concurrent pipelines and algorithmic utilities developed during the Zone01 Kisumu apprenticeship.
- **Interactive Project Filtering**: Switch between AI & GraphRAG, Fintech & Backend, and Systems & Developer Tools.
- **Direct Resume Access**: Embedded and downloadable [PDF Resume](assets/Mercy_Naliaka_Moraa_Resume.pdf).
- **Contact & Communication**: One-click clipboard copy for email and phone, plus a mailto-enabled inquiry form.

## 🚀 Running Locally

You can run this project locally without any dependencies or build tools:

```bash
# Clone the repository
git clone https://github.com/Moraa021/Mercy_Moraa_Portfolio.git
cd Mercy_Moraa_Portfolio

# Start a local static server using Python
python3 -m http.server 8000

# Open in browser: http://localhost:8000
```
