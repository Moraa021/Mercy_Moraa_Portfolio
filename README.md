## 🎨 Design Language & Aesthetic

Inspired by the tactile, human, and editorial design of [Siddhant Giri](https://www.wallofportfolios.in/portfolios/siddhant-giri/):

* **Warm Editorial Palette**: Warm cream background (`#FFF6EE`), apricot & peach tinted surfaces (`#FFCD95`, `#FFE4C7`, `#FFEBD9`), deep ink black typography (`#0F0E0D`), and rich terracotta accents (`#C25E2E`).
* **Expressive Typography**: Bold display headlines set in **Bricolage Grotesque**, paired with readable **DM Sans** for body copy and **Fira Code** for technical metadata.
* **Tactile Visuals**:
  * Retro 3D offset drop-shadow text outlines (`& SYSTEMS BUILDER`).
  * Die-cut circular portrait sticker with mouse-tracking micro-interactions and a stitched leather tag badge (`⚙️ LOW-LEVEL GO & AI SYSTEMS ⚙️`).
  * Real-world podium proof bar: **1st Prize Winner (AI Kenya Challenge)**, **2nd Prize Winner (Neo4j Graph Track)**, **Medalist (KijaniSpace Climate-Smart Agritech)**.
  * Subtle warm conic sunburst texture in the hero backdrop.
* **No AI Templates or Neon Clutter**: Designed from first principles to reflect human craft, clean code, and authentic engineering achievements.

## 🌟 Featured Production Projects

### 1. [DigiCow AI — Farmer Intelligence System](https://digicow-ai-farmer-intelligence-ui.onrender.com/) (*Kenya AI Challenge 2026*)
* **Architecture**: Python, FastAPI, Neo4j Knowledge Graph, GraphRAG, Featherless AI, Render.
* **Core Problem**: Smallholder farmers in Kenya need fast, actionable advisory without LLM hallucinations.
* **Solution**: Engineered a Neo4j knowledge graph modeling farm profiles, soil chemistry, diseases, and livestock history. Coupled with GraphRAG grounded in official KALRO & ILRI research manuals to deliver zero-hallucination bilingual advisories (English & Swahili) and priority-scored task queues for extension workers.
* **Links**: [Live Application](https://digicow-ai-farmer-intelligence-ui.onrender.com/) • [GitHub Repository](https://github.com/Moraa021/digicow-ai-farmer-intelligence)

### 2. [LedgerMate — Financial Management Platform](https://ledger-mate-ecru.vercel.app/)
* **Architecture**: Python, Flask, PostgreSQL / SQLite, SQLAlchemy, Alembic, Docker, Gunicorn, Paystack API, Vercel.
* **Core Problem**: Manual bookkeeping in Kenyan SMEs leads to errors and unreconciled mobile money payments.
* **Solution**: Integrated cryptographic Paystack webhooks (STK Push + C2B) with signature verification for 100% automated M-Pesa transaction matching; 14 REST API endpoints; inventory module with weighted-average cost tracking; automated Balance Sheet and Profit & Loss generation; linear regression forecasting.
* **Links**: [Live Application](https://ledger-mate-ecru.vercel.app/) • [GitHub Repository](https://github.com/Moraa021/LedgerMate)

### 3. [js-lings — Gamified Interactive JavaScript Testbed](https://github.com/Moraa021/js-lings)
* **Architecture**: JavaScript, Node.js, CLI Tools.
* **Overview**: Offline-first, gamified practice runner inspired by Rustlings that evaluates code locally and guides developers through mastering algorithmic concepts with instant VS Code feedback.

### 4. [Go Concurrency & Systems Engineering](https://github.com/Moraa021/pamojabuild1) (*Zone01 Kisumu Suite*)
* **Architecture**: Go (Golang), Goroutines, Channels, Data Structures, Linux.
* **Overview**: High-throughput concurrent pipelines, worker pools, memory allocation optimizations, and algorithmic engines written from first principles without external dependencies.
